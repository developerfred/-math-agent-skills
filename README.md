# math-agent-skills

Public repository of agent skills focused on **pure and applied mathematics**.

## Skill

- `skills/math/skills.md` — Complete mathematics knowledge base for agentic systems (algebra, calculus, real/complex analysis, geometry, topology, number theory, logic, probability, statistics, optimization, differential equations, numerical methods, discrete math, combinatorics, graph theory, mathematical modeling).

## Author

**codingsh** <codingsh@pm.me>

## Scope

This repository is for legitimate mathematical education, scientific computing, proofs, modeling, and defensive security understanding. Cryptographic material is included only to explain how algorithms work conceptually and how to use them correctly for protection. It must not be used to break, weaken, or attack cryptographic systems.

## Usage

Copy `skills/math/skills.md` into your agent's skills directory and reference it when the agent needs to solve mathematical problems, derive equations, verify proofs, or build models.
