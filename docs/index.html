🔍 Pesquisador

Levanta papers do arXiv, estado-da-arte, problemas em aberto, contexto histórico e referências técnicas.

👨‍🏫 Professor

Estrutura explicações didáticas, constrói provas passo a passo, cria exercícios graduados e valida clareza pedagógica.

🎓 Aluno

Deriva conceitos do zero, testa exemplos numéricos concretos, identifica lacunas de entendimento e questiona pressupostos.

🛡️ QA

Contesta teorias, busca contra-exemplos e casos extremos, valida rigor formal e reprodutibilidade numérica.

🌀 Delusional

Generates speculative, unconventional "crazy" mathematical hypotheses. Hands them to the 4-agent loop for validation or rejection.

Riemann Hypothesis — Attempted Proof Draft ========================================= Let zeta(s) = sum_{n=1}^{infty} n^{-s} for Re(s) > 1, extended by analytic continuation to C \ {1}. Conjecture: All non-trivial zeros rho of zeta(s) satisfy Re(rho) = 1/2. Approach: 1. Assume there exists a zero rho = beta + i*gamma with beta != 1/2. 2. By the functional equation, zeta(s) = zeta(1-s) up to factors, so if beta is a zero, then 1-beta is also a zero. 3. Consider the explicit formula for psi(x): psi(x) = x - sum_{rho} x^{rho}/rho - log(2*pi) - 1/2 log(1 - x^{-2}) The term x^{rho} = x^{beta} * x^{i*gamma} has magnitude x^{beta}. 4. If beta > 1/2 for some zero, the error term grows like x^{beta}, contradicting the known bound psi(x) = x + O(x^{1/2 + epsilon}) *conditional on RH itself* — circular reasoning. 5. Therefore no such beta > 1/2 can exist *unless* RH is false, which is what we are trying to prove. Status: UNRESOLVED. This draft contains circular reasoning (step 4 assumes the conclusion). Returned to Professor for reformulation. QA verdict: REJECTED — not a valid proof. — codingsh, codingsh@pm.me — Math Agent Skills Repository
