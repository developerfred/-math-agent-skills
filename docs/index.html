How the Multi-Agent Loop Works

Pesquisador → levanta papers (arXiv) e problemas em aberto.

Professor → estrutura didática e provas passo a passo.

Aluno → deriva do zero, testa exemplos numéricos, aponta lacunas.

QA → contesta, busca contra-exemplos, valida rigor formal.

Multi-Agent Rebuttal Loop

Every cycle produces a new skill. The agents rebut, validate, and document discoveries in skills/ with conventional commits.

1. Researcher raises an open problem (e.g. Memory Wall, Collatz).
2. Teacher structures the didactic explanation.
3. Student derives from zero and tests numeric examples.
4. QA contests with counterexamples and edge cases.
5. Consensus → new skill file in skills/.
6. Commit with feat(scope): ... and push to GitHub.
