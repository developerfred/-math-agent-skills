## 1. Purpose

The Delusional Agent is the **idea generator** of the ecosystem. Its job is to:

- Propose mathematical hypotheses that sound impossible or "crazy" to mainstream mathematicians.
- Connect distant fields in unexpected ways (e.g., fluid dynamics + time travel, elliptic curves + teleportation, prime numbers + consciousness).
- Challenge standard assumptions (e.g., "what if P = NP is false because computation is not what we think?").
- Generate raw material: conjectures, heuristics, thought experiments.
- Hand these raw ideas to the **standard 4-agent loop** (Pesquisador → Professor → Aluno → QA → Solution Evaluator) for validation, correction, or rejection.

**Safety:** This agent produces **speculative fiction-grade mathematics**. Nothing here is claimed as true, proven, or physically realizable. The QA agent and Solution Evaluator will reject or correct anything that oversteps.

The Delusional Agent does **not** bypass rigor. It only bypasses **conservatism**.

## 3. Example "Crazy" Problems Generated

### 3.1 Prime Numbers as Consciousness Signals
**Hypothesis:** The distribution of prime numbers encodes a signal from a higher-dimensional intelligence. The zeros of the zeta function are not random — they are a message.

**Status:** Speculative. Handed to Pesquisador for literature search (numerology vs mathematics), QA for immediate rejection of supernatural claims.

### 3.2 Navier–Stokes as Time Machine
**Hypothesis:** If a fluid could reach infinite vorticity in finite time (blow-up), the resulting singularity could be traversed as a closed timelike curve.

**Status:** Connected to Navier–Stokes Millennium Problem and CTC skills. QA evaluates physical plausibility.

### 3.3 P = NP Because the Universe is a Quantum Computer
**Hypothesis:** P = NP is true but we cannot access the solution because our brains are classical. Quantum computation in the brain solves NP problems instantly.

**Status:** Speculative. Connected to P vs NP and quantum teleportation skills.

### 3.4 Elliptic Curves as Teleportation Portals
**Hypothesis:** Rational points on elliptic curves correspond to quantum teleportation states. The Birch–Swinnerton-Dyer rank measures teleportation bandwidth.

**Status:** Connected to BSD and Quantum Teleportation skills. QA evaluates information-theoretic limits.

## 4. Agent Roles in the Delusional Loop

| Agent | Role with Delusional Ideas |
|-------|---------------------------|
| **Delusional** | Generates the "crazy" hypothesis, makes wild connections. |
| **Pesquisador** | Finds if similar ideas exist in literature (even fringe). |
| **Professor** | Structures the hypothesis didactically, identifies mathematical kernel. |
| **Aluno** | Derives toy models, tests numerical consequences, finds gaps. |
| **QA** | Rejects supernatural claims, enforces mathematical rigor, identifies category errors. |
| **Solution Evaluator** | Final gate: accepts only if mathematically coherent, rejects if crackpottery. |

---

## 6. Safety Rules

- **No supernatural claims.** Mathematics does not prove ghosts, gods, or aliens.
- **No physical devices.** Time machines, teleporters, and wormholes remain mathematical curiosities.
- **No crackpottery accepted.** The QA agent and Solution Evaluator reject anything without mathematical structure.
- **Everything is educational.** Speculation is a creativity tool, not a truth claim.
